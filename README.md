# STA

서울 도심과 시골 들녘을 누비는 한국형 온라인 오픈월드 웹게임입니다. 설치 없이 브라우저(PC·아이패드·휴대폰)에서 바로 돌아가고, 공용 서버에 접속한 사람들끼리 한 세계에서 같이 놀아요.

## 실행

- `index.html` 파일 하나로 된 게임이에요. 브라우저로 열면 바로 시작돼요.
- GitHub Pages를 켜면(Settings → Pages → Branch: `main`) `https://<아이디>.github.io/sta/` 주소로 플레이할 수 있어요.
- 3D 그래픽은 [three.js r128](https://threejs.org/)을 CDN에서 불러와요.

## 온라인 서버

`server/` 폴더가 온라인 서버예요 (Node.js + 웹소켓). 서버는 플레이어 위치·차·채팅·공격만 주고받고, 차량·행인·경찰은 각자 화면에서 따로 돌아가요.

**Render에 무료로 올리기**
1. [render.com](https://render.com)에 GitHub 계정으로 가입해요.
2. **New → Blueprint**에서 이 저장소를 고르면 `render.yaml`대로 `sta-server`가 만들어져요.
3. 만들어진 주소(예: `https://sta-server.onrender.com`)가 `index.html`의 `STA_SERVER`(`wss://…`)와 같은지 확인해요. 다르면 그 줄을 고쳐요.
4. 무료 서버는 15분 동안 아무도 없으면 잠들어요. 다음 사람이 들어오면 1분쯤 뒤에 깨어나요.

다른 서버로 접속하려면 주소 뒤에 `?server=wss://서버주소`를 붙여요. 내 컴퓨터에서 시험할 때는 `cd server && npm install && npm start` 뒤 `?server=ws://localhost:8080`.

## 조작법

| PC | 동작 |
| --- | --- |
| W A S D | 이동 · 운전 |
| 마우스 오른쪽 끌기 / 패드 두 손가락 쓸기 | 화면 돌리기 (위로 하면 하늘) |
| 마우스 왼쪽 | 누른 곳으로 쏘기 · 던지기 (맨손이면 주먹) |
| Q | 무기 바꾸기 (주먹 → 권총 → 기관단총 → 산탄총 → 수류탄) |
| G | 수류탄 |
| V | 1인칭 ↔ 3인칭 |
| F | 차 타기 · 내리기 |
| Space / Shift | 드리프트 / 달리기 |
| Enter | 채팅 |
| F (다른 플레이어 차 옆) | 같이 타기 · 내리기 |
| T | 치트 메뉴 |

터치 기기에서는 왼쪽 화면을 끌어 이동하고, 오른쪽 화면을 끌어 시점을 돌리고, 화면 버튼으로 쏘고 타요.

## 들어 있는 것

- 서울 시내, 한강과 다리, 은행나무 거리, 논밭과 과수원, 가을 산
- 승용차 · 택시 · 버스 · 1톤 트럭 · 배달 오토바이 · 경운기 · 자전거 · 구급차 · 경찰차
- 총 · 수류탄 · 주먹 싸움(가드, 잽·스트레이트·훅·어퍼컷), 수배 별과 경찰 추격, 헬기
- 1인칭 시점(조준점, 확대 조준, 운전석 안 화면)
- 배달 · 택시 · 구급차 임무, 낮·노을·밤과 날씨
- 화질 설정(높음 · 보통 · 낮음)
- 온라인: 다른 플레이어와 이름표, 주먹·총·수류탄으로 싸우기, 채팅과 말풍선, 친구 차에 같이 타기, 쓰러뜨림 알림
